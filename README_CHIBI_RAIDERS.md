# Nerdora Chibi Raiders — Live

Branch isolada usada pelo launcher GitHack do jogo.

- Link estável: https://raw.githack.com/pereiradanielc54-blip/Nerdora-player/chibi-raiders-live/index.html
- Versão atual: 9.1.0
- O launcher consulta version.json diretamente no GitHub e carrega o arquivo versionado indicado em entry.
- Para publicar uma nova versão: criar um novo arquivo em builds/ e atualizar version.json.
- manifest.webmanifest solicita fullscreen + landscape quando instalado como PWA.

A branch chibi-raiders-live é independente da main do Nerdora Player.
