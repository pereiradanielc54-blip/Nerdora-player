# Crônicas de Nerdora — Benchmark de Runs Alpha 0.3.1

## Objetivo
Medir a duração de rotas rápidas até finais alternativos e estimar uma run exploratória normal da Alpha atual.

## Método
A simulação considera:
- caminhos válidos existentes no mapa;
- rolagens D20 com atributos coerentes com a classe escolhida;
- bônus de equipamento;
- falha para frente em Derenfall;
- tempo de leitura da narração;
- tempo curto para escolher ações;
- animação do dado e deslocamento;
- 20.000 iterações estocásticas para a rota rápida de cada campanha.

Os tempos abaixo são estimativas de tempo humano no protótipo, não duração canônica de uma sessão de RPG futura.

## O Vilarejo Sem Amanhã — final rápido: O Preço de uma Lembrança
Rota:
Estrada → Portão → Praça → rastrear sino → Igreja → sino → altar → passagem → Fenda → seguir vozes → Salão → conversar → oferecer lembrança.

- decisões médias: 13,3 (inclui tentativas extras por falha);
- rolagens médias: 9,3;
- tempo no mundo: 75,8 min em média;
- tempo humano rápido: 9,2 min;
- faixa de 80% das runs rápidas: 8,2–10,3 min;
- run exploratória estimada: 17,1 min.

## A Coroa de Vidro — final rápido: A Verdade sob Juramento
Rota:
Salão dos Juramentos → investigar Coroa → Palácio → Arquivos → comparar provas → Palácio → apresentar as provas.

- decisões: 6;
- rolagens: 3;
- tempo no mundo: 32 min;
- tempo humano rápido: 4,4 min;
- faixa de 80%: 4,0–4,7 min;
- run exploratória estimada: 10,9 min.

## O Coro Abaixo — final rápido: A Canção Desviada
Rota:
Acampamento → investigar mineiros → Forja → Galeria → Túnel Impossível → investigar minério → Câmara do Coro → harmonizar.

- decisões: 7;
- rolagens: 3;
- tempo no mundo: 38 min;
- tempo humano rápido: 5,1 min;
- faixa de 80%: 4,7–5,4 min;
- run exploratória estimada: 12,0 min.

## Médias
- rota rápida média entre as três campanhas: **6,2 minutos**;
- run exploratória média da Alpha atual: **13,3 minutos**.

## Interpretação
A Alpha ainda é curta comparada à meta de campanha final. Para o produto completo:
- aventura curta: 20–35 min;
- sessão padrão: 45–90 min;
- capítulo longo: 90–150 min;
- campanha persistente: várias sessões.

Derenfall já se aproxima melhor da sensação desejada. Coroa de Vidro e Coro Abaixo precisam de mais cenas intermediárias, NPCs, subtramas, consequências e obstáculos opcionais para uma run normal chegar à faixa de 20–30 minutos sem alongamento artificial.
